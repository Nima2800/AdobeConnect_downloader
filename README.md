# Adobe Connect Local Web UI

یک رابط وب فارسی، ساده و کاربردی برای تبدیل کلاس‌های ضبط‌شده Adobe Connect به فایل MP4.

بدون تنظیمات پیچیده، بدون نیاز به ورود خودکار به کلاس و بدون کار کردن مستقیم با دستورات طولانی؛ لینک کلاس را وارد کنید، فایل ZIP را دانلود و آپلود کنید و خروجی ویدیو بگیرید.

---

## شروع سریع

برای استفاده از برنامه فقط سه مرحله دارید:

1. پیش‌نیازها را نصب کنید.
2. برنامه را اجرا کنید.
3. فایل ZIP کلاس را وارد کرده و رندر را شروع کنید.

---

## 1. نصب پیش‌نیازها

برنامه فقط به **Python** و **FFmpeg** نیاز دارد.

اگر این دو مورد از قبل روی سیستم شما نصب هستند، مستقیم به بخش اجرای برنامه بروید.

<details>
<summary><strong>نصب Python در ویندوز</strong></summary>

1. وارد سایت رسمی Python شوید:

   [دانلود Python](https://www.python.org/downloads/)

2. روی دکمه Download Python کلیک کنید.

3. فایل دانلودشده را اجرا کنید.

4. قبل از زدن دکمه Install، حتماً گزینه زیر را فعال کنید:

   ```text
   Add Python to PATH
   ```

5. روی Install Now کلیک کنید.

برای بررسی نصب، CMD یا PowerShell را باز کرده و دستور زیر را وارد کنید:

```powershell
python --version
```

اگر شماره نسخه Python نمایش داده شد، نصب با موفقیت انجام شده است.

</details>

<details>
<summary><strong>نصب Python در لینوکس</strong></summary>

در بیشتر توزیع‌های لینوکس، Python از قبل نصب است.

برای بررسی:

```bash
python3 --version
```

اگر Python نصب نبود، در Ubuntu یا Debian دستور زیر را اجرا کنید:

```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv
```

</details>

<details>
<summary><strong>نصب FFmpeg در ویندوز</strong></summary>

ساده‌ترین روش، استفاده از WinGet است.

PowerShell یا Windows Terminal را باز کرده و دستور زیر را اجرا کنید:

```powershell
winget install --id Gyan.FFmpeg --exact
```

بعد از پایان نصب، پنجره Terminal را ببندید و دوباره باز کنید.

سپس دستورهای زیر را وارد کنید:

```powershell
ffmpeg -version
ffprobe -version
```

اگر اطلاعات نسخه نمایش داده شد، FFmpeg آماده استفاده است.

اگر WinGet روی سیستم شما کار نکرد، می‌توانید FFmpeg را از سایت رسمی آن دانلود کرده و پوشه `bin` را به PATH ویندوز اضافه کنید:

[دانلود FFmpeg](https://ffmpeg.org/download.html)

</details>

<details>
<summary><strong>نصب FFmpeg در لینوکس</strong></summary>

### Ubuntu و Debian

```bash
sudo apt update
sudo apt install -y ffmpeg
```

### Arch Linux و Manjaro

```bash
sudo pacman -S ffmpeg
```

### Fedora

```bash
sudo dnf install ffmpeg-free
```

برای بررسی نصب:

```bash
ffmpeg -version
ffprobe -version
```

</details>

## 2. دریافت و آماده‌سازی پروژه

پروژه را دانلود یا Clone کنید:

```bash
git clone <repository-url>
cd adobe_connect_web_ui
```

سپس کتابخانه‌های موردنیاز را نصب کنید:

### ویندوز

```powershell
python -m pip install -r requirements.txt
```

### لینوکس و macOS

```bash
python3 -m pip install -r requirements.txt
```

<details>
<summary><strong>استفاده از محیط مجازی Python — اختیاری</strong></summary>

استفاده از محیط مجازی اجباری نیست، اما باعث می‌شود کتابخانه‌های پروژه از سایر برنامه‌های Python جدا بمانند.

### ویندوز

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

### لینوکس و macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

</details>

## 3. اجرای برنامه

### ویندوز

روی فایل زیر دوبار کلیک کنید:

```text
run_ui.bat
```

یا آن را از PowerShell اجرا کنید:

```powershell
.\run_ui.bat
```

### لینوکس و macOS

```bash
chmod +x run_ui.sh
./run_ui.sh
```

بعد از اجرای برنامه، مرورگر را باز کرده و وارد آدرس زیر شوید:

```text
http://127.0.0.1:5000
```

## نحوه استفاده
1. وارد lms بشید و وارد کلاس مد نظر بشید (باید دقیقا دکمه پلی کلاس بیاد براتون)
1. لینک کلاس را توی برنامه وارد کنید.
2. برنامه لینک دانلود فایل ZIP را می‌سازد.
3. فایل ZIP را به‌صورت دستی دانلود کنید.
4. فایل دانلودشده را داخل برنامه آپلود کنید.
5. کیفیت و اجزای موردنظر ویدیو را انتخاب کنید.
6. روی دکمه شروع پردازش بزنید.
7. روند ساخت ویدیو را به‌صورت زنده مشاهده کنید.
8. بعد از آماده شدن خروجی، فایل MP4 را پخش یا دانلود کنید.

* عدم نیاز به ورود برنامه به Session کلاس

## کیفیت‌های خروجی

| کیفیت   | مناسب برای                       |
| ------- | -------------------------------- |
| `360p`  | سیستم‌های ضعیف و خروجی سریع      |
| `480p`  | بهترین انتخاب برای اکثر کاربران  |
| `720p`  | کیفیت بهتر روی سیستم‌های قوی‌تر  |
| `1080p` | بالاترین کیفیت و پردازش سنگین‌تر |

### پیشنهاد ما

برای بیشتر لپ‌تاپ‌ها و کامپیوترها، کیفیت `480p` بهترین انتخاب است.

این حالت تعادل مناسبی بین موارد زیر ایجاد می‌کند:

* کیفیت تصویر
* سرعت پردازش
* مصرف CPU
* حجم فایل خروجی

کیفیت‌های `720p` و `1080p` زمان بیشتری برای پردازش نیاز دارند.

## انتخاب اجزای داخل ویدیو

هنگام ساخت خروجی می‌توانید مشخص کنید کدام قسمت‌ها داخل ویدیو نمایش داده شوند:

* PDF و اسلایدها
* Screen Share
* Chat
* Pointer
* Annotation
* صدا

برای سریع‌تر شدن رندر می‌توانید بخش‌های غیرضروری مانند Chat، Pointer و Annotation را خاموش کنید.

اگر Screen Share برای شما مهم نیست، خاموش کردن آن بیشترین تأثیر را روی سرعت پردازش دارد.

---

## رندر سریع‌تر با کارت گرافیک NVIDIA

اگر کارت گرافیک NVIDIA GTX 1050 یا بالاتر دارید، گزینه زیر را در برنامه فعال کنید:

> گرافیک NVIDIA GTX 1050 یا بالاتر دارم

برنامه تلاش می‌کند از قابلیت NVENC کارت گرافیک برای ساخت سریع‌تر ویدیو استفاده کند.

اگر کارت گرافیک، درایور یا FFmpeg از NVENC پشتیبانی نکند، برنامه به‌صورت خودکار از CPU استفاده می‌کند و پردازش متوقف نمی‌شود.

<details>
<summary><strong>بررسی پشتیبانی از NVENC</strong></summary>

در ویندوز:

```powershell
ffmpeg -hide_banner -encoders | findstr nvenc
```

در لینوکس:

```bash
ffmpeg -hide_banner -encoders | grep nvenc
```

اگر عبارت زیر نمایش داده شد، انکودر NVENC در FFmpeg موجود است:

```text
h264_nvenc
```

</details>

## نمایش زنده روند ساخت ویدیو

بعد از شروع پردازش، مستقیماً وارد صفحه پلیر می‌شوید.

در این صفحه می‌توانید موارد زیر را مشاهده کنید:

* وضعیت فعلی پردازش
* درصد پیشرفت
* لاگ‌های برنامه
* آخرین فریم ساخته‌شده
* قسمت‌های آماده‌شده ویدیو
* فایل MP4 نهایی

تا قبل از آماده شدن ویدیوی کامل، آخرین فریم رندرشده به‌عنوان پیش‌نمایش نمایش داده می‌شود.

---

## پخش ویدیو قبل از پایان کامل رندر

ویدیو هنگام پردازش به قسمت‌های تقریباً ۱۰ دقیقه‌ای تقسیم می‌شود.

هر قسمت بلافاصله بعد از آماده شدن داخل پلیر نمایش داده می‌شود؛ بنابراین برای مشاهده ویدیو لازم نیست تا پایان کامل رندر منتظر بمانید.

بعد از آماده شدن تمام قسمت‌ها، برنامه آن‌ها را به یک فایل MP4 کامل تبدیل می‌کند.

## ساختار پروژه

| مسیر            | کاربرد                             |
| --------------- | ---------------------------------- |
| `app.py`        | سرور Flask و APIهای رابط وب        |
| `web_runner.py` | اجرای رندر و مدیریت تنظیمات خروجی  |
| `templates/`    | صفحات HTML                         |
| `static/`       | فایل‌های CSS، JavaScript و فونت‌ها |
| `outputs/`      | ویدیوهای نهایی                     |
| `uploads/`      | فایل‌های ZIP آپلودشده              |
| `jobs/`         | فایل‌های موقت پردازش               |

## فونت Kalameh Fanum

برای نمایش رابط با فونت Kalameh Fanum، فایل‌های فونت را داخل مسیر زیر قرار دهید:

```text
static/fonts/
```

فایل `static/style.css` از قبل برای وزن‌های مختلف فونت تنظیم شده است.

بدون این فونت نیز برنامه قابل استفاده است و مرورگر از فونت جایگزین استفاده خواهد کرد.
